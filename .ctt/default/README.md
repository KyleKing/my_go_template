## Installation



### GH CLI Extension

> **Note:** Requires a [GitHub Release](https://github.com/user_ctt/test-template/releases) with precompiled binaries. See [CONTRIBUTING.md](CONTRIBUTING.md#releases) for creating the first release.

```bash
gh extension install user_ctt/test-template
```

### Homebrew

goreleaser publishes a cask to [`user_ctt/homebrew-tap`](https://github.com/user_ctt/homebrew-tap) with each release, so the install needs `--cask`:

```bash
brew install --cask user_ctt/tap/test-template
```

### Go Install


```bash
go install github.com/user_ctt/test-template/cmd/test-template@latest
```
